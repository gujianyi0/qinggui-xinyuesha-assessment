## Kafka＋独立Worker＋PostgreSQL

Kafka 3.9.1官方归档SHA512校验通过。先在SQLite下验证两轮，分块变更后的证据为[native-kafka-20261110-02](evidence/native-kafka-20261110-02/summary.json)。随后在真实PostgreSQL上执行同样六项，原始证据：[PG＋Kafka摘要](evidence/native-postgres-20261110-02-kafka/summary.json)。

| 场景 | 观测结果 |
| --- | --- |
| 写库后、提交位点前退出 | Worker按故障点退出82；位点为未提交`-1001`，重启后提交到1；尝试仍为1，分块仍为659 |
| 重复投递 | 同任务、旧代次重复消息被确认，尝试仍为1，没有重复最终业务记录 |
| 持久延迟重试耗尽 | 临时故障最多3次，最终failed，保留原因；验证退避缩短为1/1秒，生产默认10/30秒 |
| 坏输入后正常任务 | 坏快照在第一次结束失败，后一正常任务成功 |
| 领取后退出 | Worker退出83；租约过期后恢复，最终成功，尝试2次、generation3 |
| Broker不可用后恢复 | 停Broker时任务和Outbox先落PG；重启Broker后自动投递并成功 |

测试使用独立Topic和Consumer Group，显式启用受控故障点；正常配置不会因`ASSESSMENT_CRASH_AT`或`ASSESSMENT_JOB_FAULT`意外触发退出。六项故障矩阵为缩短执行时间使用测试向量；真实BGE/pgvector由上一节单独验证，未将这两段混称为同一任务用了真实BGE。

清理时发现Oracle javapath启动垫片可能留下子JVM，已确认并关闭本轮配置对应的Broker，修正脚本为解析java.home并直接启动实际java.exe。未结束其他Java或网页进程。

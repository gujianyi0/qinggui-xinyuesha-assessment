# 真实模型运行与前后对照

更新：2026-11-17。

## 对应要求

> 留下真实模型的运行结果，看看引用是否正确、工具是否选对、任务是否完成，记下耗时和用量。比较修改前后的效果时，用同一组样例，并说明测了哪些情况。

## 本项目回答与证据

真实模型运行保存在[results](../../../evaluations/results/)；不是pytest的模型替身。每轮保留metadata、逐条results.jsonl和summary，逐条包含回答、工具、引用、耗时、token和费用。费用缺失/估算必须保留标识；不以模型声称调用工具代替实际审计。

同组比较使用[full-01](../../../evaluations/results/live-v19-full-01/)、[full-02](../../../evaluations/results/live-v19-full-02/)、[full-03](../../../evaluations/results/live-v19-full-03/)、[full-04](../../../evaluations/results/live-v19-full-04/)的同一32条规格。检查模型、提示词、环境与样例哈希后再比较。第四轮V01超时原记录仍在，[V01补测](../../../evaluations/results/live-v19-retry-v01/)作为同版本补测单列，不能宣称一次运行无失败。

[逐条答案与来源核对](../../完整32条真实回归-1.9-20261113.md)和[引用完整性审计](../../../evaluations/results/live-v19-full-04/citation-audit.json)分别记录语义与引用。最终采用结果109处引用通过完整性核验，不等于所有新问题均正确。核对工具选择、任务完成和条件匹配时保留人工复核结论。

最近的[2.0.1修复](../../2.0.1-裁定话题与输入草稿修复-20261117.md)有[真实前后原始结果](../../evidence/v201-live-regression-20261117.json)：修前3次、修后5次与浏览器1次，已结算费用0.109748元。这是针对性复测，没有重跑最新版本全部32条。原32条回归不能改名成v2.0.1完整回归。本轮简单卡牌性能优化也将单独保存同组配对结果，静态查表路径不冒充模型生成。

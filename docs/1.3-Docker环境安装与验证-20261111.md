安装位置：当前用户LOCALAPPDATA下Programs/DockerDesktop。安装器已加入用户PATH；本次旧进程仍继承安装前PATH，首次hello-world找不到docker-credential-desktop。保留该失败记录后，仅为测试进程补入Docker resources/bin，再次实际拉取并运行成功；未删除凭据配置或更改系统代理。

现有终端需要重新打开以继承新PATH；也可在PowerShell使用完整路径：

```powershell
& "$env:LOCALAPPDATA\Programs\DockerDesktop\resources\bin\docker.exe" version
& "$env:LOCALAPPDATA\Programs\DockerDesktop\resources\bin\docker.exe" compose version
```

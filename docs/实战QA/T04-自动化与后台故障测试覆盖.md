## 本项目如何实现

| 原文覆盖点 | 对应代码与检查 |
|---|---|
| 非法输入与未知字段 | [test_api.py](../../tests/test_api.py)：非法消息、鉴权、额外字段、坏快照拒绝 |
| 模型格式、空正文、工具异常 | [test_agno_protocol.py](../../tests/test_agno_protocol.py)：真实SDK配受控HTTP，校验失败/引用/资源关闭 |
| 超时与并发 | [test_runtime.py](../../tests/test_runtime.py)、Agno协议超时；检查运行与费用状态 |
| 会话/运行/反馈/任务隔离 | API双身份测试及真实容器重启后隔离记录 |
| 重复提交与反馈确认 | API唯一约束、修订冲突、重复确认返回同记录 |
| 重复消费与并发领取 | [test_jobs.py](../../tests/test_jobs.py)：同代次只领取一次，发布事务保护 |
| Worker中断与重启 | 租约失效、旧代次隔离；实际SIGKILL、进程重启及60秒恢复 |
| 重试耗尽与坏输入 | 持久retry_wait、3次耗尽、坏输入终止后其他任务继续 |
| 位点及异常 | [test_worker.py](../../tests/test_worker.py)：坏信封处理、失败位置回退，防后续提交跳过消息 |

网页断线恢复、焦点/IME和重复点击行为由前端测试与真实浏览器记录补充。测试环境中的时间推进、模型替身和注入点须保持显式，不拿加速单测证明实际10/30秒间隔。

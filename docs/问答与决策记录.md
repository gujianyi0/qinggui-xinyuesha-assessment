## 必须保留的业务规则

1. 反馈先形成草稿，明确展示后由本人确认，才写入正式反馈。重复确认不能重复记录，过期修订号要求重新查看。
2. 模型输出、正文、昵称和群管理员身份不授予跨会话读取或写入权限。
3. 两个测试身份验证会话、运行、反馈和任务隔离；共享游戏资料另行标识为公共资料。
4. 暂存索引全部成功后原子发布；取消不能被迟到的重试或旧Worker覆盖。
5. Redis只缓存资料检索结果；PostgreSQL保留业务权威状态。
6. 本次材料中的公司硬要求、项目工程默认和外部待确认事项分别标识。

回答

本项目已经打通这条链路：React输入通过FastAPI进入应用，校验身份和会话归属后创建Run；Runtime使用Agno异步调用模型与受控工具；工具回执、最终正文、引用、用量和状态写入PostgreSQL，网页从SSE或轮询读取结果。

本项目如何实现

主要入口在main.py的create_app、create_run与受理接口。模型执行在runtime.py的Runtime.execute：Agno负责模型/工具循环，应用负责权限、预算、取消和最终保存。

网页默认发送POST /sessions/{id}/submissions，先返回202和run_id，本机再GET运行事件流，公网轮询GET /runs/{id}。历史POST /sessions/{id}/runs流式接口仍用于评测。消息及Run先落库，不能把HTTP已受理等同于模型已完成。

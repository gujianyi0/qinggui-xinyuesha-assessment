# 2.0.4 位置预览与共享进度恢复

日期：2026-11-17，轻归版本2.0.4-local.1，本机15180内测。

用户反馈位置链接会下载，并补充要求在49篇知识文档旁附上进度，恢复文章中的掌握、收藏和下载控件。确认继续使用用户本人的共享进度，考核官查看。

## 位置链接

- 按仓库相对路径在轻归内打开项目文件、目录或报告，不依赖F盘、用户名或克隆目录。源码和日志按每页100行展示，支持行号跳转；Markdown按段落阅读，目录可展开已导出文件，PNG可预览。
- 下载改为独立的“下载此文件”或“下载原文”操作。代码正文作为文本展示，不执行HTML/脚本；长行分段展开，避免一次排版巨大文件。
- 仅允许检阅清单中已导出的路径，私有配置和未收录文件不读取。浏览器无法自动推断别人电脑的克隆根目录；本轮实现站内对应位置预览，没有实现桌面资源管理器跳转。

## 共享掌握与收藏

- 沿用原知识书架Cloudflare D1记录。接入前实测48条已掌握、revision=40；没有重置为0，也没有自动把第49篇标成掌握。
- 原服务同步补齐第49篇知识文档及进度目录，Worker版本`d90fa69b-c878-4a7b-adba-ee42b545b866`；[原服务核对](evidence/v204-original-shelf-sync-20261117.json)。轻归v2公网前端仍未发布。
- 本机后端保存管理口令，alice可维护共享掌握状态，bob及其他身份只读。修改带revision；考核资料8-xx不能提交学习状态。原有48条掌握ID保留，实际同值写入仅使revision从40增加为41，未增加或取消任何掌握条目。
- 知识区恢复进度条、已掌握标记、收藏文章和下载原文。收藏按登录身份隔离保存在各自浏览器；主人可以兼容读取本机同源旧书架的收藏，保留旧存储，不把原Cloudflare域名的浏览器收藏伪装成已自动跨域迁移。
